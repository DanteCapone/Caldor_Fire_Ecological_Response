# Caldor Fire Ecosystem Response

Code used to generate the main and supplemental figures and analyses for the
Lake Tahoe Caldor Fire study.

Run from the repository root:

```r
source("scripts/main_analysis/run_all.R")
source("scripts/main_analysis/supplemental_figures.R")
source("scripts/build_supplemental_final.R")
```

Figure 1 is generated separately with
`source("scripts/caldor_forcing_v2.R")`. Project data and generated figures are
not included in this repository.
